IMPORTANT:
This is a starter web app/PWA, NOT yet a signed Android APK/AAB and NOT ready for Google Play publication.
It does not yet include a live AI service, online accounts, cloud database, payment/subscription system, privacy policy, or admin/content management.
Before publishing: replace sample content with reviewed material, configure a secure backend if needed, create a privacy policy and support contact, test accessibility and different devices, build a signed Android App Bundle, and complete Google Play Console's current developer/account and app requirements.
Never put secret API keys directly in frontend JavaScript.

Quick test:
Open index.html in a browser, or host the folder on an HTTPS static host. For offline/PWA features, use HTTPS or localhost.
